# Play Store Reset Request

## Purpose
This file documents the process for requesting a Play Store app reset or version bump when needed.

## When to Reset
- Major version upgrade required
- Bundle ID change
- Re-signing with new keystore
- Migration to new Play Store account

## Steps
1. Notify Google Play support at support.google.com/googleplay
2. Provide app package name and justification
3. Wait for approval (typically 24-48 hours)
4. Update version in `build.gradle` after approval
